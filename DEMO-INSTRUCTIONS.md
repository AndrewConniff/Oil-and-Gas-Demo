# Demo Instructions: Oil and Gas Demo

Classification: Public

## Fictional company disclaimer

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Objective

Show trainers how to deliver concise, oil-and-gas-themed Microsoft 365 Copilot, Copilot Chat, Copilot in Apps, and agent demos for a fictional field operations audience.

## Target audience

- Business leaders who need executive-ready updates.
- Field operations managers who need concise site summaries.
- HR and learning leads who support adoption.
- IT and AI champions who support enablement and office hours.
- Frontline or field personnel who need practical AI assistance.

## Course-order demo flow

### 1. MS-4023: Copilot Chat basics

Use `prompts/copilot-chat-prompts.md`.

Run prompts in this order:

1. Summarize field updates.
2. Identify operational risks.
3. Draft follow-up questions.
4. Create an office-hours answer.
5. Prepare an AI champion handoff.

Expected outcome: participants see how Copilot Chat can reason over pasted public-safe fictional notes without requiring Microsoft 365 Copilot licensing.

### 2. AI-3025: Microsoft 365 Copilot basics

Use `prompts/m365-copilot-prompts.md`.

Run prompts in this order:

1. Draft an executive update from fictional field notes.
2. Convert operational notes into action items.
3. Create a concise stakeholder brief.
4. Compare risks across field sites.

Expected outcome: licensed users see how Microsoft 365 Copilot can accelerate daily knowledge work.

### 3. Copilot in Word and PowerPoint

Use the Word and PowerPoint prompts in `prompts/m365-copilot-prompts.md`.

Run prompts in this order:

1. Word: create a field operations summary.
2. Word: refine the summary for executives.
3. PowerPoint: create a status deck from the summary.
4. PowerPoint: simplify slides for a leadership readout.

Expected outcome: participants see how field notes become polished business artifacts.

### 4. Copilot in Teams, Outlook, and OneNote

Use the Teams, Outlook, and OneNote prompts in `prompts/m365-copilot-prompts.md`.

Run prompts in this order:

1. Teams: summarize a fictional operations thread.
2. Outlook: draft a follow-up message.
3. OneNote: organize office-hours questions.
4. Outlook or Teams: prepare the next-step handoff.

Expected outcome: participants see how Copilot supports communication, follow-up, and knowledge capture.

### 5. Agents: field operations knowledge assistant

Use `prompts/agent-builder-instructions.md`.

Run prompts in this order:

1. Introduce the fictional Field Operations Knowledge Assistant.
2. Review grounding content.
3. Test field update summarization.
4. Test safety and risk triage.
5. Test AI champion support answers.

Expected outcome: participants understand how an agent can provide consistent answers from approved fictional knowledge sources.

### 6. Optional trainer-prep workflow with Scout or Cowork

Use `prompts/scout-cowork-prompts.md`.

Run prompts in this order:

1. Summarize trainer requirements.
2. Create a trainer handoff checklist.
3. Draft a follow-up one-pager.
4. Identify open questions for the delivery team.

Expected outcome: trainers see how AI can help prepare, coordinate, and follow up.

### 7. CIE-style field immersion readiness

Use `setup/cie-readiness-checklist.md`.

Run prompts in this order:

1. Confirm site logistics.
2. Confirm participant personas and counts.
3. Confirm room technology and trainer support.
4. Confirm AI champion coverage.
5. Confirm follow-up and office-hours plan.

Expected outcome: trainers have a repeatable readiness structure for onsite field immersion events.

## Concise talk track

"This scenario uses a fictional Microsoft Fake Company called Fabrikam Field Energy. The goal is to show how Microsoft 365 Copilot, Copilot Chat, Copilot in Apps, and agents can help field operations teams summarize updates, spot risks, prepare executive communications, coordinate follow-up, and support AI champions. All data is fictional and Public."

## Troubleshooting

- If Copilot cannot access content, paste the fictional sample notes directly into the prompt.
- If app-specific Copilot features are unavailable, use the Copilot Chat alternative prompt.
- If an agent cannot be created, walk through the instructions and test cases as a design review.
- If a user asks about real customer data, state that this repository is Public and must use fictional data only.

## Cleanup

Remove any temporary files created during delivery. Do not save real customer data into this repository or into generated demo artifacts.
