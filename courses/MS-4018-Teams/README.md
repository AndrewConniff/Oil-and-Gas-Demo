## Demo order

1. **Open the Teams sample thread** - Use artifacts/Fabrikam_Teams_Operations_Thread.md as the public-safe conversation source.
2. **Summarize the discussion** - Ask Copilot in Teams for key decisions and unresolved questions.
3. **Find action items** - Ask for owners, actions, and follow-up themes.
4. **Create a recap message** - Ask Copilot to draft a message for AI champions.
5. **Prepare office-hours topics** - Ask for common question themes to address next.
