## Scope

Copilot in PowerPoint for turning a readiness story into a leadership deck.

## Demo order

1. **Open the readiness deck** - Use artifacts/Fabrikam_Field_Readiness_Update.pptx.
2. **Summarize the deck** - Ask Copilot for the story, risks, and decisions.
3. **Create or refine slides** - Ask Copilot to add a slide for leadership decisions.
4. **Simplify the talk track** - Ask for a concise speaker flow for field leaders.
5. **Generate follow-up content** - Ask for a closing slide with office-hours and AI champion actions.
