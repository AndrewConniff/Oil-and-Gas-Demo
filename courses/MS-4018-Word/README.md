Classification: Public

## Fictional company disclaimer

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Scope

Copilot in Word for creating, rewriting, and tightening an operations brief.

## Demo order

1. **Open the Word brief** - Use artifacts/Fabrikam_Field_Operations_Brief.docx.
2. **Summarize the brief** - Ask Copilot in Word for key points and decisions needed.
3. **Rewrite for executives** - Ask for a shorter leadership-ready version.
4. **Create action items** - Ask for actions grouped by owner role.
5. **Adjust tone** - Ask Copilot to make the brief direct, practical, and field-operations focused.

## Prompts

### Prompt 1

```text
Summarize this document for field operations leaders in five bullets.
```

### Prompt 2

```text
Rewrite this brief as an executive update with decisions needed and next actions.
```

### Prompt 3

```text
Create a table of action items with owner role, due-date placeholder, and expected outcome.
```

### Prompt 4

```text
Make the tone concise, practical, and suitable for a field readiness meeting.
```
