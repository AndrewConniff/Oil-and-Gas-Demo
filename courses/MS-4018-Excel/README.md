# MS-4018: Copilot in Excel

Classification: Public

## Fictional company disclaimer

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Scope

Copilot in Excel plus licensed chat handoff using Analyst and the Excel-specific Copilot experience.

## Demo order

1. **Open the Excel workbook** - Use artifacts/Fabrikam_Field_Operations_Analysis.xlsx.
2. **Review the Field Data sheet** - Show site, readiness, backlog, safety observations, and adoption columns.
3. **Ask Copilot in Excel for insights** - Find highest-risk sites, summarize trends, and suggest questions.
4. **Create a table or chart** - Ask Copilot in Excel to visualize readiness by site and risk level.
5. **Use Analyst in licensed chat** - Ask Analyst to interpret the workbook as a business-readiness story.
6. **Return to Excel for depth** - Use Copilot in Excel to add a formula, create a summary, and inspect outliers.

## Prompts

### Prompt 1
