# MS-4023: Unlicensed Copilot Chat

Classification: Public

## Fictional company disclaimer

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Scope

Copilot Chat only. No Microsoft 365 file grounding and no app-specific Copilot.

## Demo order

1. **Open Copilot Chat** - Use a work account with Copilot Chat access and start a new chat.
2. **Paste public sample notes** - Use only the fictional field notes in shared/sample-data/field-operations-notes.md.
3. **Summarize field updates** - Ask for a five-bullet summary by site, risk, and next action.
4. **Find risk themes** - Ask Copilot Chat to identify common risks and missing follow-up questions.
5. **Draft a safe response** - Ask for a field manager reply that avoids confidential data.
6. **Create an office-hours answer** - Ask for a concise answer about safe prompting for field teams.

## Prompts

### Prompt 1

```text
Summarize these fictional field operations notes in five bullets by site, risk, and next action.
```

### Prompt 2

```text
Identify the top three common risks across these fictional sites and suggest one follow-up question for each.
```

### Prompt 3

```text
Draft a concise field manager update using only the fictional notes below. Do not add metrics or facts that are not present.
```

### Prompt 4

```text
Explain how field teams can use Copilot Chat safely without entering confidential production data.
```

## Public-safe delivery notes

- Use only fictional Fabrikam Field Energy data.
- Do not include real customer names, tenant details, private URLs, or confidential metrics.
- Keep the technology focus limited to this folder's course or app.
