# Copilot Chat Prompts

Classification: Public

## Fictional company disclaimer

This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

Use these prompts for MS-4023-style Copilot Chat demos. Paste fictional sample data from `sample-data/field-operations-sample.json` when needed.

## Prompt order

### 1. Summarize field updates

```text
Summarize these fictional Fabrikam Field Energy site updates in five bullets. Focus on production impact, safety items, staffing concerns, and next actions.
```

### 2. Identify operational risks

```text
Review these fictional field notes and list the top operational risks. For each risk, include why it matters and one suggested next step.
```

### 3. Draft follow-up questions

```text
Create five follow-up questions an operations manager should ask before the next field leadership sync.
```

### 4. Create an office-hours answer

```text
Answer this fictional office-hours question for an AI champion: "How can field supervisors use Copilot Chat without entering confidential production data?" Keep the answer practical and concise.
```

### 5. Prepare an AI champion handoff

```text
Create a short handoff note for AI champions supporting a field operations training session. Include what to watch for, what to reinforce, and what questions to capture.
```
